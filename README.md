# Urban Voice
Urban Voice is a Flutter-based Smart City Report & Feedback System that enables citizens to report civic issues, upload images, and track complaint status. This application was developed as an academic group project using Flutter, Dart, and Firebase.

## Features
- User Authentication
- Report civic issues
- Upload issue images
- Track complaints
- Firebase Integration
- Smart City Dashboard

## Tech Stack
- Flutter
- Dart
- Firebase

## Team Project
Developed as part of an academic group project.
